# invisible-data-workers

This is an  interactive Streamlit dashboard to analyze and visualize wage inequalities. This way, we can see which big companies like OpenAI, Amazon etc are recruiting data annotator for poorer countries like Kenya, India...

## Files
* `testing.py` – [What the script runs/outputs]
* `workers.csv` – [Where the data comes from or what's inside]

## Running it

```bash
git clone https://github.com
cd invisible-data-workers
pip install -r requirements.txt
python testing.py
```

## Data (`workers.csv`)
Contains few rows covering countries, task types and hourly rates.
